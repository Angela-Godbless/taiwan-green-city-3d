# 植感城市 3D V8.1 遊戲啟動修正版

本版本延續 V8 的城市、全螢幕、環保任務和工人施工功能。新增：
- 開場「▶ 立即試玩」會自動開始第一棵九芎的植樹流程。
- 若 HTML 預覽器未執行 JavaScript，明顯顯示啟動提示。
- 保留全螢幕／縮小畫面操作，適用桌機及手機畫面。

## iPhone 如何玩
ChatGPT 的 HTML 附件預覽、iOS 檔案 App 的 Quick Look 預覽可能不執行 JavaScript，因此會看到介面但操作沒有反應。
請將 ZIP **解壓縮**，把 `index.html`、`src/`、`assets/` 上傳新的 GitHub Repo。進入 Settings → Pages → Deploy from a branch，Branch 選 `main`，Folder 選 `/(root)` 並儲存，待網站發布後，用 Safari 開啟 GitHub Pages 網址。
**不要只把 ZIP 檔當作網站檔案上傳；網站需要解壓後的內容。**

## 遊玩測試
1. 點「▶ 立即試玩：園丁種一棵樹」。
2. 預算從 $2,200 降為 $2,015，工人從基地出發。
3. 工人依序挖土、扶苗、澆水、整理植穴。
4. 工程完成後成功植栽從 0 變 1。
5. 可按下一天、選擇其他樹木、開啟全螢幕。

此程式是台灣環境保育的教育模擬，不是實務植栽施工指引。
